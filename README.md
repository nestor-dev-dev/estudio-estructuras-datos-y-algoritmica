# Estructuras de Datos y Algorítmica en Java

Repositorio de estudio personal que recopila implementaciones propias desde cero de estructuras de datos fundamentales y algoritmos clásicos, orientado a profundizar en su funcionamiento interno y análisis de complejidad.

## Tecnología
- **Lenguaje:** Java

## Contenido
- **Estructuras de Datos:** Implementación manual de pilas, colas, listas enlazadas, árboles y sus operaciones básicas.
- **Algorítmica y Complejidad:** Implementaciones de algoritmos de ordenación (*Merge Sort*, *Quick Sort*), divide y vencerás, *backtracking* y resolución de problemas algorítmicos.
